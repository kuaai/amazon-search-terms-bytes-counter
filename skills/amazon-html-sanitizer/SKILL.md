# Amazon Product Description HTML Sanitizer

1. Strip all disallowed tags (`<div>`, `<span>`, `<script>`, `<h1>`-`<h6>`).
2. Remove all inline styles and class attributes.
3. Validate output uses only `<p>`, `<b>`, `<br>`, `<ul>`, and `<li>`.
4. Output clean Amazon Seller Central compliant copy.
